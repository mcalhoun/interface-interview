NO LANGUAGE MODEL PRODUCED THIS RUN
===================================

Read this before reading events.jsonl.

This directory is the output of the ticket-10 discovery loop driving the real
Heritage Core fixture in a real Chromium, under the real policies/default.yaml,
with a SCRIPTED stand-in where the model goes. Every decision in events.jsonl was
written by a hand-coded function in test/support/scripted-model.ts, not by an
LLM. The `decide` events are real events emitted by the real loop; the judgement
behind them is not a model's.

WHY
---
The OPENAI_API_KEY present in the build environment is revoked. It returns 401
from OpenAI's own /v1/models endpoint, and the 1Password vault holding a
replacement is locked and needs a human to unlock it. So the one thing this
ticket could not do is the one thing that cannot be stubbed: a real LLM-driven
run. That gap is stated here rather than papered over.

WHAT THIS DIRECTORY DOES DEMONSTRATE
------------------------------------
Everything below the model, end to end and for real:

  * the loop drives a live browser from a natural-language goal and reaches the
    balance, $4,182.55, behind an unnamed iframe on a page with no test IDs
  * every action passed the Policy chokepoint first (the policy.check events)
  * each decision is recorded with its rationale beside the action (decide)
  * a screenshot per step, and none of them entered a prompt (ADR-0001)
  * the member number appears nowhere in events.jsonl, because the scrubber grew
    as the values were discovered — grep for 12345 and get nothing

TO PRODUCE A REAL ONE
---------------------
With a working key in OPENAI_API_KEY, this is one command and no code change:

  bun run discover "Look up the savings account balance of member 12345"
